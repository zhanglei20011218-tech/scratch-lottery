# 福彩刮刮乐 · 模拟器

纯静态单页应用，**双击 `index.html` 即可运行**，无需依赖或服务器。开局余额 ¥100。

## 票面样式

按市面即开票的竖版版式重做：

- 竖版整票比例，彩色票头 + 米白票底 + 左右齿孔/撕线
- 顶部品牌条：原创「福」字徽标、中国福利彩票、英文名、面值
- 艺术字票名、票种系列、完整玩法说明
- 银色刮开区与「刮开区」角标，刮开约 50% 自动揭晓
- 底部：最高奖、兑奖期限 60 天、随机条形码、16 位票号、发行机构、模拟票章
- 票架改为竖版票样陈列：缩略票面 + 面值 + 玩法 + 中奖率/返奖率 + 购买按钮

## 玩法说明

- **号码匹配**：刮开后「我的号码」与「中奖号码」相同，即中该号码下方奖金。
- **找图符**：刮出指定图符（金币 / 福 / 吉），即中该格奖金。
- **奖金翻倍**：号码命中后奖金按票面倍数翻倍，结果区标注「已含 ×2」。

## 文件
